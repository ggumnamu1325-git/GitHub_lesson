구분선 추가 방법

안댁상 벙법

  1. 번호를 붙여서
  2. 표현을 하면
  3. 자동으로 만들어 집니다.

불릿(bullet)으로 표현하는 방법

  • +를 사용해서 표현하거나
  • -를 사용해도 되고
  • *를 써도 됩니다.
    • 이렇게 탭(TAB)을 누르면
    • 들여쓰기가 됩니다.
텍스트를 강조하는 방법
  • 굵게 표현하는 방법은 이렇게 하거나
  • 또는 이렇게 하면 BOLD로 표현된다
  • 글자를 기울이는방법은
  • 이렇게 중간에 언더바 로 감싸면 된다
    • 굵으면서도 기울이게 하려면 이렇게 하거나
    • 이렇게 하면 된다.

취소선은 이렇게하면 표현이 가능합니다.

클릭하면 열리는 구글 링크

글 중간에 단어 형태의 짧은 코드를 넣을 때(백틱 1개(옵션 누르고 클릭))

printf("Hello, World")

는 영어 상태일 때는 잘 되는데, 한글은 옵션을 눌러야 함

# 여러 줄 코드를 넣을 때(백티 3개 + 언어 이름)
print("Hello, World")

// 여러 줄
printf("Hello, World")

체크 리스트

  • 아직 안 한 일 (대괄호 안에 띄어쓰기 1칸)
  • 완료한 일 (대괄호 안에 소문자 x)
